MineAgent is a client-side [Fabric](https://fabricmc.net) mod for Minecraft 26.3. You give it an API key for a language model and a goal such as `get 3 iron ingots`, and the model plays your character until the goal is done or it explains why it stopped.

The model plays mostly without seeing the screen. It calls tools that read the world (`observe`, `find_blocks`, `recipes`...) and tools that act in it (`walk_to`, `gather`, `craft`, `smelt`...). Each action runs tick by tick as normal player input, so it works in singleplayer and on servers with nothing installed server-side.

## Using it

1. Put the [jar](https://github.com/CuteTenshii/MineAgent/releases/latest) and [Fabric API](https://modrinth.com/mod/fabric-api) in your `mods` folder.
2. Pick a provider with `/agent config`, then enter its key with `/agent key`.
3. Give it a goal: `/agent goal build a crafting table and a wooden pickaxe`.

While it works, a box on screen shows the current action and the tokens spent, and its path is drawn in the world. Add instructions with `/agent say`, or take control back with `/agent stop`. If it needs a decision, it asks in chat and waits for your answer. The README has the [full command list](https://github.com/CuteTenshii/MineAgent#commands).

## What it can do

- **Get around:** an [A\*](https://en.wikipedia.org/wiki/A*_search_algorithm) pathfinder that sprints, jumps, swims, climbs ladders, opens doors, breaks what's in the way and pillars up. In creative it can fly.
- **Gather and build:** mine, place blocks, and pick up drops, with the best tool it carries.
- **Use every workstation:** crafting through the recipe book, furnaces, stonecutter, smithing table, anvil, enchanting table, grindstone, brewing stand, and chests.
- **Work with other mods:** it's told which installed mods add blocks, items and mobs, and uses their crafting tables, furnaces and other stations.
  - With [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap) or [JourneyMap](https://modrinth.com/mod/journeymap) it reads your waypoints and adds new ones, so `go back to my base` works without coordinates.
  - With [REI](https://modrinth.com/mod/rei) or [JEI](https://modrinth.com/mod/jei) it sees every way an item is made, not just crafting: when `craft` finds no recipe, it's told what makes the item instead, such as a furnace or another mod's machine.
- **Stay alive:** it fights back when a mob hits it, swims up for air, and tells the model about damage, hunger and harmful effects. If the player dies, it respawns and tells the model where and how, so it can go back for its items.
- **Look**, on models that accept images: a screenshot of the player's view with the HUD hidden.
- **Read the wiki:** it looks up a [minecraft.wiki](https://minecraft.wiki) page and reads its introduction or one section, such as Obtaining. You can turn this off in the settings.
- **Teleport** with `/tp` when the server allows it, and **run other commands** only after you turn on "Allow server commands" in the settings, and only commands the server lets the player use.

The README lists [every tool](https://github.com/CuteTenshii/MineAgent#what-the-agent-can-do) the model gets and how each one behaves.

## Providers

Anthropic is called through the Messages API, with prompt caching. OpenAI, Gemini, DeepSeek, Mistral, Groq, xAI, OpenRouter and [Ollama](https://ollama.com) all go through the OpenAI Chat Completions API, and any other service that speaks it works with a custom base URL. Both use the JDK's HTTP client and the Gson library Minecraft already ships. The only library bundled in the jar is [Cloth Config](https://modrinth.com/mod/cloth-config), for the settings screen. The [provider table](https://github.com/CuteTenshii/MineAgent#providers) gives each one's default model and key variable.

Long goals can use a lot of tokens: a goal pauses after 200 model turns and waits for you to continue it.
